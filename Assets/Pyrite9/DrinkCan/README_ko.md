# Pyrite9 Drink Can

버전 0.1.0 (2026-10-24)

VRChat 아바타용 음료 캔 기믹입니다. 휴머노이드 아바타에 프리팹을 넣기만 하면 빌드할 때 그 아바타의 손에 캔을 맞춥니다.
꺼내서 캔을 따고, 한 모금씩 마시고, 빈 캔을 던져 버릴 수 있습니다.

English: `README_en.md` / 日本語: `README_jp.md` / 이용 규약: `LICENSE.txt` / 라벨 가이드: `Labels/LabelGuide_ko.md`

## 기능

- 꺼내기·따기·한 모금씩 마시기·던지기 — 데스크톱은 메뉴 버튼, VR은 손가락으로 따개를 올려 따고 캔을 입에 대서 마십니다
- 캔을 기울여도 음료는 수평을 유지하며 마시는 입구로 보이고, 한 모금마다 줄어듭니다
- 맥주 거품(딸 때 솟아오르는 거품 돔과 15초쯤 지나면 사라지는 거품층 — 사라지면 음료 색이 보입니다) 또는 탄산(딸 때 튀는 방울), 거품 색도 고를 수 있습니다
- 빈 캔은 휘둘러 던질 수 있고 바닥을 굴러갑니다. 착지 소리는 떨어지는 시간에 맞춰 납니다
- 플레이 중 메뉴로 손 바꾸기
- 크기(프리셋 4종 또는 높이·지름 마음대로)·라벨 이미지·음료 색을 마음대로
- 빌드 때 아바타 손에 맞춰 손가락이 캔을 감싸거나(자동), 직접 정한 손 모양을 씀(수동)
- 주변 월드를 비추는 알루미늄(lilToon·리플렉션 프로브)

## 필요한 것

- Unity 2022.3(VRChat)
- VRChat SDK – Avatars 3.10 이상
- Modular Avatar
- NDMF(Non-Destructive Modular Framework)
- lilToon 2.x(VPM 판·`.unitypackage` 판 모두 가능)

확인한 환경: Unity 2022.3.22f1, VRChat SDK Avatars 3.10.5, Modular Avatar 1.18.7, NDMF 1.14.8, lilToon 2.3.4·2.4.1(새로 만든 빈 아바타 프로젝트에서도 확인).
이보다 오래된 버전(lilToon 1.x 포함)과 프리뷰 버전(alpha·beta)은 확인하지 않았습니다.

- 캔은 꺼내지 않은 동안에도 약 24,000 삼각형과 머티리얼 슬롯을 최대 7개 더하므로 퍼포먼스 랭크가 내려갈 수 있습니다(자세한 건 "참고").
- 같은 아바타의 Android / Quest 판도 올린다면, Android로 빌드하기 전에 `DrinkCan` 오브젝트를 지우세요(끄기만 해서는 빠지지 않습니다).

## 설치

1. **필요한 패키지를 넣습니다.** VCC / ALCOM에서 아바타 프로젝트를 "관리"(Manage Project)로 열고 **Modular Avatar**와 **lilToon**을 추가합니다.
   NDMF는 Modular Avatar와 함께 자동으로 들어갑니다. 안정판(프리뷰가 아닌 버전)을 쓰세요.
   - 목록에 없으면 먼저 각 패키지 공식 사이트의 "Add to VCC"로 저장소를 추가하세요.
   - lilToon이 이미 `.unitypackage`로 들어 있다면(아바타에 동봉된 경우가 많고 `Assets/lilToon`에 있음) 두 번 넣지 마세요. 그게 1.x라면 lilToon 안내에 따라 업데이트하세요.
2. **이 패키지를 임포트합니다.** `.unitypackage`를 더블클릭(또는 Unity의 `Assets > Import Package > Custom Package…`)하고, 모두 체크한 채 **Import**를 누릅니다. 파일은 `Assets/Pyrite9/DrinkCan/`에 들어갑니다.

## 사용법

1. Project 창에서 `Assets/Pyrite9/DrinkCan/`을 열고 `DrinkCan.prefab`을 Hierarchy의 아바타(VRC Avatar Descriptor가 붙은 오브젝트)에 끌어다 놓습니다. 아바타의 자식이 됩니다.
   - 아바타 안이면 어디든 괜찮습니다. **아바타 밖(씬 바로 아래 등)에 있으면 아무 일도 일어나지 않습니다.**
   - 프리팹을 Unpack하지 마세요(업데이트가 반영되지 않습니다).
2. Hierarchy에서 `DrinkCan`을 고르면 인스펙터가 나옵니다. 첫 구역(기본)의 **Menu language**(`EN` / `日本語` / `한국어`)에서 **한국어**를 고르면 인게임 메뉴와 인스펙터가 한국어로 바뀝니다(기본값 EN).
3. (선택) 다른 설정을 바꿉니다(아래 "설정"). 인스펙터 위쪽의 **손에 든 모습 미리보기**로 아바타 손에 든 모습을 볼 수 있습니다.
4. 시험해 봅니다:
   - Unity에서 **Play**를 누르면 캔이 빌드되고 인스펙터의 **마지막 빌드**가 채워집니다(Play를 멈춘 뒤 표시). Play 모드에서는 메뉴가 동작하지 않으니 VRChat에서 확인하세요.
   - `VRChat SDK > Show Control Panel > Builder` → **Build & Test** 뒤 VRChat에서 테스트 아바타로 갈아입고 **음료 캔** 메뉴에서 **꺼내기** → **따기** → **마시기** 순서로 눌러 봅니다.
   - 문제없으면 **Build & Publish**. Build & Test는 내 화면만 보여 줍니다 — 남에게 어떻게 보이고 들리는지는 (Private으로) 업로드한 뒤에 확인할 수 있습니다.
5. 결과를 확인합니다. 정상적으로 맞춰졌다면 **마지막 빌드**에 아바타 이름·빌드 시각과 **경고: 없음**이 나옵니다.
   - "아바타 안(VRC Avatar Descriptor가 있는 오브젝트 밑)에 넣어 주세요."가 나오면 캔이 아바타 밖에 있는 것입니다. 빌드한 뒤에도 "아직 빌드 기록이 없습니다"가 그대로 나오면 빌드가 캔까지 닿지 않은 것입니다(Console에 빨간 컴파일 오류가 없는지 확인하세요).
   - 경고는 Console(`Window > General > Console`)에도 `[Pyrite9 Drink Can] WARN`으로 시작하는 노란 줄로 나옵니다 — "문제 해결"을 보세요. 자세한 내용은 프로젝트 폴더의 `Logs/Pyrite9_DrinkCan_build.txt`에 적힙니다.

빌드할 때 아바타의 손과 머리를 재서 캔 크기(손과 아바타 키로), 양손 각각의 쥐는 자리, 캔을 감싸는 손가락 모양, 입 위치를 맞춥니다. 씬은 바뀌지 않습니다 — 바뀌는 건 빌드용 사본뿐입니다.

## Expression Menu

메인 메뉴에 서브메뉴 **음료 캔** 하나가 추가됩니다(표시는 **메뉴 언어**를 따릅니다):

| 항목 | 종류 | 파라미터 | 하는 일 |
|---|---|---|---|
| 꺼내기 | 토글 | `Pyrite9/DrinkCan/Out` | 켬: 따지 않은 가득 찬 새 캔을 손에 듦. 끔: 캔을 던짐(손에서 떨어지거나 손이 움직이는 쪽으로 날아감). "집어넣기" 동작은 없고, 던진 캔은 멈추고 8초 뒤에 사라집니다 |
| 따기 | 버튼 | `Pyrite9/DrinkCan/OpenBtn` | 캔을 땀 |
| 마시기 | 버튼 | `Pyrite9/DrinkCan/Drink` | 캔을 입으로 가져가 한 모금 — **먼저 따세요**(안 딴 캔·빈 캔은 아무 일도 없음) |
| 손 바꾸기 | 토글 | `Pyrite9/DrinkCan/SwapHand` | 캔을 반대 손으로 |

동기화 파라미터: **12비트**(`Out`·`Opened`·`Level`·`Drink`·`SwapHand`, 모두 `Pyrite9/DrinkCan/` 아래). 아바타 전체에서 256비트까지이고, 넘으면 SDK가 업로드를 막습니다.
저장하지 않습니다 — 아바타를 다시 불러오면 캔은 꺼내지 않은 상태로 돌아갑니다. 다른 파라미터(`OpenBtn`·콘택트·센서)는 로컬 전용입니다.

## 인게임 동작

| | 데스크톱 | VR |
|---|---|---|
| 꺼내기 | 메뉴 `꺼내기` | 같음 |
| 따기 | 메뉴 `따기` | **반대 손 검지**로 따개를 건드림(메뉴 버튼도 됨) |
| 마시기 | 메뉴 `마시기` — 캔이 입으로 갔다 돌아옴(1.6초), 한 모금 | 캔 윗부분을 잠깐 **입에 댐** — 한 모금. 뗐다가 다시 대면 다음 모금(메뉴 버튼도 됨) |
| 던지기 | `꺼내기`를 끔 — 캔이 앞에 떨어져 조금 구름 | 손을 휘두르며 `꺼내기`를 끔 — 그쪽으로 날아감. **빈 캔은 휘두르기만 해도 던져집니다**(마지막 모금 1초 뒤부터) |
| 손 바꾸기 | 메뉴 `손 바꾸기` | 같음 |
| 새 캔 | `꺼내기`를 껐다가 다시 켬 | 같음 |

- 던진 캔은 바닥에 떨어져 구르다 멈추고, 8초 뒤에 사라집니다(새 캔을 꺼낼 때도 사라짐).
- 캔을 따고 마실 수 있는 건 본인뿐입니다. 캔·딴 상태·남은 양·던진 캔은 다른 사람에게도 보입니다.
- 소리: 따는 소리와 착지 소리는 모두에게 들립니다(2 m까지 그대로, 5 m에서 안 들림). 꿀꺽 소리는 본인에게만 들립니다. 각 음량은 인스펙터(소리)에서 바꿀 수 있습니다.

## 설정(Drink Can 컴포넌트)

메뉴 언어를 한국어로 했을 때 인스펙터에 보이는 이름입니다.

| 구역 | 항목 | 뜻 |
|---|---|---|
| 기본 | 메뉴 언어 | `EN` / `日本語` / `한국어` — 메뉴 표시(빌드 때 적용)와 인스펙터 언어. 기본값 EN |
| | 꺼내는 손 | 오른손(기본값) / 왼손 — 꺼낼 때 캔을 쥐는 손. 메뉴 **손 바꾸기**로 플레이 중에 바꿀 수 있고, 아바타를 다시 불러오면 이 손으로 돌아옵니다 |
| | 쥐는 손 모양 — 손가락으로 캔을 감싸기 | 켬(기본값): 들고 있는 동안 그 손의 손가락이 캔을 감싸고, 그 손의 손가락 트래킹은 멈춥니다. 끔: 손가락은 그대로 |
| 캔 | 크기 | 350(66 × 122 mm, 기본값) / 500(66 × 168) / 250 슬림(53 × 133) / 190 커피(53 × 104) / 직접 — 고르면 높이·지름이 자동으로 들어갑니다 |
| | 높이·지름 | mm(높이 60~220, 지름 45~90). 바꾸면 크기가 '직접'으로 바뀝니다. 게이지를 두 번 누르면 프리셋 값으로 돌아갑니다 |
| | 라벨 | 캔의 곧은 몸통에 감는 이미지. **비우면 무지 알루미늄.** **템플릿 열기**는 고른 크기용 템플릿을, **라벨 가이드**는 가이드를 엽니다(아래 "라벨 그리기") |
| | 라벨 맞춤 | 늘림(몸통에 꽉) / 비율 유지(이미지 비율대로 한 바퀴 — 가로로 긴 이미지는 위아래에 금속 띠, 세로로 긴 이미지는 위아래가 잘림) / 반복(캔 둘레에 나란히) |
| 음료 | 액체 색 | 마시는 입구로 보이는 색 |
| | 모금 수 | 빌 때까지 모금 수(3~10, 기본값 6) |
| | 거품 | 없음 / 탄산(콜라·사이다) / 맥주 거품(기본값) |
| | 거품 색 | 거품층과 딸 때 거품·방울의 색 |
| 소리 | 따는 소리 | 따개를 올려 따는 소리. 주변 사람에게도 들립니다. 1 = VRChat 아바타가 낼 수 있는 최대, 0 = 끔(기본값 1) |
| | 꿀꺽 소리 | 한 모금마다 나는 소리. 나에게만 들립니다(기본값 0.5) |
| | 착지 소리 | 던진 캔이 바닥에 떨어지는 소리. 주변 사람에게도 들립니다(기본값 1) |
| 미세 조정 | 크기 배율 | 손에 대한 캔 크기(0.5~2). 1 = 실제 손에 실제 캔 |
| | 손바닥 바깥 / 손끝 쪽 / 엄지 쪽 | 손 기준으로 캔을 옮김(미터, 아바타 기준 크기에서). 반대 손에서는 좌우 대칭 |
| | 돌림 | 캔을 축 둘레로 돌림(도) |
| | 손끝 쪽 기울임 / 손바닥 바깥 기울임 | 캔의 가운데를 중심으로 기울임(도) |
| 쥐는 손 모양 | 맞춤 | **자동**(기본값): 손가락이 캔에 닿을 때까지 굽히고, 손이 가장 잘 감기는 자리에 캔을 놓음(빌드마다 몇 초, 세밀한 손은 최대 20초 정도. 쥐는 모양을 못 찾으면 수동 모양을 씀). **수동**: 손가락 슬라이더(휴머노이드 근육 값. 움직이면 수동으로) |
| | 기본 모양으로 | 슬라이더를 기본 손 모양으로 되돌림 |
| | 내보내기… / 불러오기… | 손 모양과 캔 위치·돌림·기울임을 `.json`으로 저장하거나 불러옴(다른 아바타의 캔에도. 불러오면 수동으로 바뀜) |

인스펙터에는 이 밖에 다음이 있습니다(표시는 메뉴 언어를 따릅니다):

- **버전**: 하루 한 번 GitHub에 최신 버전을 묻고, 새 버전이 있으면 알려 줍니다(아래 "참고").
- **손에 든 모습 미리보기**: 지금 설정으로 아바타 사본을 만들어 손에 캔을 쥐여 줍니다(몇 초 걸림). Scene 뷰에서만 보이고 씬에 저장되지 않습니다. **켜 둔 동안 원래 아바타는 Scene 뷰에서 숨겨집니다.** 끄면 원래대로 돌아옵니다. 설정을 바꾸면 **새로 고침**을 누르세요.
- **마지막 빌드**: 마지막 Play·Build & Test·업로드·미리보기의 아바타·시각·캔 배율·손 길이·꺼내는 손·모금 수·경고. 빌드 로그와 이 README를 여는 버튼이 있습니다. **확인**을 누르면 확인한 경고를 그 아바타에서는 접어 둡니다.

- 크기별 견본 라벨도 4장 더 있습니다(가상의 브랜드, 크기마다 1장). 같은 **크기**를 고르고 Project 창에서 PNG를 **라벨** 칸에 끌어다 놓으세요:
  `DrinkCan_Label_WhiteStatic_500ml.png`(에너지 드링크, 500 ml) · `DrinkCan_Label_RidgeDry_350ml.png`(라거, 350 ml) · `DrinkCan_Label_NightLimeCola_250mlSlim.png`(라임 콜라, 250 ml 슬림) · `DrinkCan_Label_DailyBean_190gCoffee.png`(커피, 190 g).
- 직접 만든 라벨은 `Assets/Pyrite9/DrinkCan/` 안이 아니라 내 폴더(예: `Assets/MyLabels/`)에 두세요.
- 직접 만든 이미지를 넣으면 다음 Play나 업로드 때 **NDMF** 창(Console에도)에 "Some of your textures have mip streaming disabled."가 뜰 수 있습니다 — 거기서 **Auto Fix**를 누르세요. 또는 이미지를 골라 임포트 설정의 **Streaming Mipmaps**를 켜고 **Apply**. VRChat SDK 빌더에는 이 항목이 나오지 않습니다.

## 문제 해결

Console 경고는 영어로 나옵니다(`Build failed`만은 빨간 오류로만 나옴). 인스펙터 **마지막 빌드**에는 같은 경고가 메뉴 언어로 나옵니다(아래 표의 괄호 안).

| Console 메시지(`[Pyrite9 Drink Can] WARN …`) 또는 증상 | 할 일 |
|---|---|
| 임포트 직후 `error CS0246: The type or namespace name 'nadena' could not be found`나 `error CS0234: … 'modular_avatar' does not exist in the namespace 'nadena.dev'` 같은 빨간 오류가 나고 Play·빌드가 안 됨 | Modular Avatar(및 NDMF)가 설치되지 않았습니다. VCC / ALCOM에서 Modular Avatar를 추가하면 Unity가 다시 컴파일한 뒤 오류가 사라집니다. |
| 캔이 분홍색이거나 금속이 이상하게 보임 | lilToon이 없거나 너무 오래됐습니다. lilToon 2.x를 넣으세요("설치"). |
| `The can needs a humanoid avatar with a VRC Avatar Descriptor — not built`(휴머노이드 아바타가 필요합니다) | 휴머노이드 아바타(Rig: Humanoid, 루트에 VRC Avatar Descriptor)만 지원합니다. |
| `Hand or head bone missing — not built`(손 또는 머리 본이 없습니다) | 아바타의 휴머노이드 본 매핑(손·머리)을 확인하세요. |
| `No lip-sync visemes — the mouth is guessed from the view position`(립싱크 비즘이 없습니다) | 아바타 디스크립터에서 립싱크 비즘을 설정하거나 View Position을 조절하세요. 데스크톱에서 마실 때 입에 안 맞을 수 있습니다. |
| `Hand lengths differ by more than 10 % …`(양손 길이가 10 % 넘게 다릅니다) | 캔 크기는 '꺼내는 손'에 맞춥니다. 보통은 괜찮습니다. 반대 손에서 어색하면 크기 배율로 조절하세요. |
| `Right/Left hand: hand / index finger bones missing`, `no skinned mesh on the hand`, `no hand vertices on …`(기본 쥐는 자리, 손 모양 없음) | 그 손은 손 모양 없이 기본 쥐는 자리가 됩니다. 손가락 본 매핑을 확인하세요. |
| `Right/Left hand: the hand pose does not fit this avatar …`(손 모양이 이 아바타에 맞지 않습니다) | 그 손의 손가락은 컨트롤러를 따릅니다. **쥐는 손 모양 ▸ 맞춤**을 **수동**으로 바꾸고 미리보기를 보며 슬라이더로 조절한 뒤 **새로 고침**하세요. |
| `Right/Left hand: the hand sinks … mm into the can`(손이 캔에 파고듭니다) | **손바닥 바깥**으로 캔을 옮기거나 **크기 배율**을 낮추세요. |
| `… DrinkCan components — only the first one is built`(DrinkCan 컴포넌트가 …개 있습니다) | 캔은 아바타에 하나만. 남는 것을 지우세요. |
| `Build failed: …`(빌드 실패), Console에 빨간 오류 | 캔이 빠졌거나 불완전합니다(아바타의 나머지는 빌드됨). 빨간 오류와 `Logs/Pyrite9_DrinkCan_build.txt`를 보내 주세요("문의"). |
| `Material template missing …`, `liquid mask material not found`, `particle shader not found`, `foam texture missing`, `sound … not found`, `throw particle mesh not made`, `no metal material` | 패키지 파일이 빠졌거나 프리팹이 수정됐습니다. 아바타에서 캔을 지우고 `DrinkCan.prefab`을 다시 넣고, 안 되면 패키지를 다시 임포트하세요. |
| 음료 캔 메뉴가 안 보임 | 프리팹이 아바타 밖에 있거나, "— not built(만들지 않았습니다)" 경고로 빌드가 멈췄습니다(위 표). 고친 뒤 다시 빌드·업로드하세요. |
| 메뉴가 영어로 나옴 | 인스펙터의 **Menu language**를 **한국어**로 바꾸고 다시 빌드하세요. |
| `마시기`를 눌러도 아무 일이 없음 | 먼저 캔을 따세요(`따기`, VR은 반대 손 검지로 따개). 빈 캔은 못 마십니다 — 새 캔을 꺼내세요. |
| 휘둘러도 안 던져짐 | 휘둘러 던지기는 **빈 캔**만 됩니다(마지막 모금 뒤 1초 기다리세요). 어떤 캔이든 `꺼내기`를 끄면 던져집니다. |
| 손가락으로 따도 반응이 없음 | **반대쪽** 손 검지로 따개 고리를 건드리세요. 데스크톱은 `따기` 버튼. |
| 캔을 쥔 손의 손가락이 안 움직임 | 들고 있는 동안은 원래 그렇습니다. 손가락을 자유롭게 두려면 **쥐는 손 모양 — 손가락으로 캔을 감싸기**를 끄세요. |
| 손에 쥔 캔 위치가 이상함 | 미리보기를 켜고 미세 조정(손바닥 바깥·손끝 쪽·엄지 쪽·돌림·기울임) 또는 쥐는 손 모양을 조절하세요. |
| 캔이 너무 크거나 작음 | 크기는 손과 아바타 키를 따릅니다. 미리보기를 켜고 **크기 배율**(0.5~2)로 조절하세요. |
| 따는 소리·착지 소리가 남에게 안 들림 | 상대가 내 아바타 소리를 허용하고(VRChat Safety·아바타 표시) 아바타 음량을 올려 두어야 합니다. 5 m 넘게 떨어지면 안 들립니다. 따는 소리·착지 소리가 0이 아닌지도 확인하세요. |
| 꿀꺽 소리가 안 들림 | **꿀꺽 소리**(기본값 0.5)를 올리고 VRChat 오디오 설정에서 아바타 음량을 확인하세요. |
| SDK에 파라미터가 256비트를 넘는다고 나옴 | 캔은 동기화 파라미터를 12비트 씁니다. 다른 기믹의 파라미터를 줄이거나 동기화를 꺼서 비우세요. |
| 라벨이 흐리거나 늘어나거나 이음매에서 잘리거나 검정·흰 얼룩이 보임 | `Labels/LabelGuide_ko.md`("이미지 팁", "라벨 맞춤")를 보세요. 템플릿 크기로 그리기, Compression을 High Quality로, 투명은 쓰지 않기. |
| 던진 캔이 바닥을 뚫고 떨어짐 | 캔은 Default·Environment 레이어의 콜라이더(월드 바닥)에만 착지하고, 나머지는 통과합니다. |

## 업데이트·제거

- **업데이트:** 새 패키지를 위에 덮어 임포트합니다(모두 체크한 채 Import). 설정은 씬의 `DrinkCan` 오브젝트에 저장돼 있어서 그대로 남습니다. `Assets/Pyrite9/DrinkCan/` 안의 파일(프리팹·머티리얼·템플릿)은 고치지 마세요 — 업데이트로 덮어써집니다. 직접 만든 라벨과 내보낸 `.json`은 내 폴더에 두세요.
- **아바타에서 빼기:** 아바타의 `DrinkCan` 오브젝트를 지웁니다. Hierarchy에서 오브젝트를 꺼도 캔은 빌드에서 **빠지지 않습니다**.
- **프로젝트에서 지우기:** 먼저 아바타에서 캔을 빼고, 그다음 `Assets/Pyrite9/DrinkCan/` 폴더를 지웁니다. 아바타의 `DrinkCan` 오브젝트에 "Missing (Mono Script)"가 보이면 그 오브젝트를 지우세요(Missing Script가 있으면 SDK가 업로드하지 않습니다).
- 인스펙터의 변경 기록은 이 README에서 읽어 옵니다 — README 파일은 패키지 폴더에 그대로 두세요.

## 참고

- 휴머노이드 아바타만. 캔은 아바타에 하나.
- FX 레이어 7개와 Gesture 레이어 최대 3개(하나는 빈 레이어, 나머지는 들고 있는 동안 쥔 손의 손가락만 움직임, 쥐는 손 모양을 끄면 없음)를 씁니다. 레이어는 아바타의 Write Defaults 설정에 맞춰지므로(Modular Avatar "Match Avatar Write Defaults") WD 켬·끔 아바타 모두에서 동작합니다.
- Action·Base·Additive 레이어는 쓰지 않아 GoGo Loco·이모트와 같이 쓸 수 있습니다(데스크톱에서 마실 때도 움직이는 건 캔뿐이고 팔은 안 움직임). Gesture 레이어에서 손가락을 움직이는 다른 기믹이 있으면 쥐는 모양을 덮어쓸 수 있습니다.
- 음료의 수평은 아바타 루트 기준입니다 — 아바타를 기울이는 스테이션에서는 같이 기웁니다.
- 던진 캔은 저폴리 사본(따개·입구 없음)이고, 보는 사람마다 떨어지는 자리가 조금 다를 수 있습니다.
- 착지 소리는 캔이 손 바로 아래로 떨어진다고 가정하고 재생합니다 — 세게 던지면 조금 일찍, 손 아래쯤에서 납니다. 바닥이 손에서 6 m보다 아래면 착지 소리가 나지 않습니다.
- 데스크톱에서 마실 때 잠깐 캔이 시점 바로 앞에 옵니다.
- Unity 에디터에서 Drink Can 인스펙터를 열면 하루 한 번 GitHub(`api.github.com`)에 이 패키지의 최신 버전을 묻습니다. 보내는 정보는 없고, 버전 글자를 누르면 바로 다시 확인합니다.
- 퍼포먼스(350 ml·맥주 거품): 약 24,000 삼각형(캔 21,864), 머티리얼 슬롯 최대 7, PhysBone 3(기울기·휘두름 센서), Contact 수신 2 + 송신 1, Constraint 7, 파티클 시스템 4(던진 캔 포함·충돌 켬, 탄산이면 5), 오디오 소스 2, VRC Raycast 1, 메뉴 아이콘 5(256×256). 라이트 없음. 캔을 꺼내지 않은 동안에도 모두 집계됩니다.
