# Pyrite9 Drink Can

バージョン 0.1.0（2026-10-24）

VRChat アバター用の飲み物の缶ギミックです。ヒューマノイドのアバターにプレハブを入れるだけで、ビルド時にそのアバターの手に缶を合わせます。
取り出して、プルタブを開けて、一口ずつ飲んで、空き缶を投げ捨てられます。

English: `README_en.md` / 한국어: `README_ko.md` / 利用規約: `LICENSE.txt` / ラベルの作り方: `Labels/LabelGuide_jp.md`

## 機能

- 取り出す・開ける・一口ずつ飲む・投げ捨てる。デスクトップはメニューのボタンで、VR は指でプルタブを起こし、缶を口に当てて飲みます
- 缶を傾けても液面は水平を保ち、飲み口から中が見えます。一口ごとに減ります
- ビールの泡（開けるときに盛り上がる泡のドームと、約 15 秒で消えていく泡の層。消えると飲み物の色が見えます）または炭酸（開けるときのしぶき）。泡の色も選べます
- 空き缶は振って投げられ、床を転がります。着地音は落ちる時間に合わせて鳴ります
- プレイ中にメニューで持ち替え
- 大きさ（プリセット 4 種、または高さ・直径を指定）・ラベル画像・飲み物の色を変えられます
- ビルド時にアバターの手に合わせて指が缶を握る（自動）、または好きな手の形を指定（手動）
- 周りのワールドを映すアルミ（lilToon・リフレクションプローブ）

## 必要なもの

- Unity 2022.3（VRChat）、**PC 専用**（Android / Quest 非対応）
- VRChat SDK – Avatars 3.10 以降
- Modular Avatar
- NDMF（Non-Destructive Modular Framework）
- lilToon 2.x（VPM 版・`.unitypackage` 版どちらでも）

動作確認環境: Unity 2022.3.22f1、VRChat SDK Avatars 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8、lilToon 2.3.4 と 2.4.1（新規作成した空のアバタープロジェクトでも確認）。
これより古いバージョン（lilToon 1.x を含む）とプレビュー版（alpha・beta）は確認していません。

- 缶はしまっている間も含めて約 24,000 ポリゴン・マテリアルスロット最大 7 を追加するため、パフォーマンスランクが下がることがあります（詳細は「補足」）。
- 同じアバターの Android / Quest 版もアップロードする場合は、Android でビルドする前に `DrinkCan` オブジェクトを削除してください（オフにするだけでは外れません）。

## 導入

1. **必要なパッケージを入れる。** VCC / ALCOM でアバターのプロジェクトを「管理」（Manage Project）で開き、**Modular Avatar** と **lilToon** を追加します。
   NDMF は Modular Avatar と一緒に自動で入ります。安定版（プレビューでない版）を使ってください。
   - 一覧にない場合は、先にそれぞれの公式サイトの「Add to VCC」でリポジトリを追加してください。
   - lilToon がすでに `.unitypackage` で入っている場合（アバターに同梱されていることが多く、`Assets/lilToon` にあります）は、二重に追加しないでください。それが 1.x なら、lilToon の案内に従って更新してください。
2. **このパッケージをインポートする。** `.unitypackage` をダブルクリック（または Unity の `Assets > Import Package > Custom Package…`）し、すべてチェックしたまま **Import** を押します。ファイルは `Assets/Pyrite9/DrinkCan/` に入ります。

## 使い方

1. Project ウィンドウで `Assets/Pyrite9/DrinkCan/` を開き、**`DrinkCan.prefab`** を Hierarchy のアバター（VRC Avatar Descriptor が付いたオブジェクト）にドラッグします。アバターの子になります。
   - アバターの中ならどこでも構いません。**アバターの外（シーンの直下など）にあると何も起きません。**
   - プレハブを Unpack しないでください（パッケージを更新しても反映されなくなります）。
2. Hierarchy で `DrinkCan` を選ぶとインスペクターが出ます。最初の区分（基本）の **Menu language**（`EN` / `日本語` / `한국어`）で **日本語** を選ぶと、ゲーム内のメニューとインスペクターが日本語になります（初期値は EN）。
3. （任意）ほかの設定を変えます（下の「設定」）。インスペクター上部の **手に持った姿をプレビュー** で、アバターの手に持たせた姿を確認できます。
4. 試す:
   - Unity の **Play** を押すと缶がビルドされ、インスペクターの **最後のビルド** に結果が表示されます（Play を止めたあと）。Play モードではメニューは動かないので、動きは VRChat で確かめます。
   - `VRChat SDK > Show Control Panel > Builder` → **Build & Test** のあと、VRChat でテスト用のアバターに着替えて **ドリンク缶** メニューを開き、**取り出す** → **開ける** → **飲む** の順に試します。
   - 問題なければ **Build & Publish**。Build & Test で見えるのは自分の画面だけです。ほかの人にどう見えるか・聞こえるかは（Private で）アップロードしてから確認できます。
5. 結果を確認します。正常に調整できていれば、**最後のビルド** にアバター名・ビルドした時刻と **警告: なし** が出ます。
   - 「アバターの中（VRC Avatar Descriptor のオブジェクトの下）に入れてください。」と出たら、缶がアバターの外にあります。ビルドしたのに「まだビルドの記録がありません」のままなら、ビルドが缶まで届いていません（Console に赤いコンパイルエラーが出ていないか確認してください）。
   - 警告は Console（`Window > General > Console`）にも、**`[Pyrite9 Drink Can] WARN`** で始まる黄色い行で出ます。「困ったとき」を見てください。詳細はプロジェクトフォルダの `Logs/Pyrite9_DrinkCan_build.txt` に書き出されます。

ビルド時にアバターの手と頭を測り、缶の大きさ（手とアバターの背丈から）・左右それぞれの持ち位置・缶を握る指の形・口の位置を調整します。シーン自体は変更されません（変更されるのはビルド用のコピーだけです）。

## Expression Menu

メインメニューにサブメニュー **ドリンク缶** が 1 つ追加されます（表示は **メニュー言語** に従います）:

| 項目 | 種類 | パラメーター | 内容 |
|---|---|---|---|
| 取り出す | トグル | `Pyrite9/DrinkCan/Out` | オン: 未開封で満タンの新しい缶を手に持つ。オフ: 缶を投げる（手から落ちる、または手の動きの方向へ飛ぶ）。「しまう」動きはなく、投げた缶は止まってから 8 秒後に消えます |
| 開ける | ボタン | `Pyrite9/DrinkCan/OpenBtn` | プルタブを開ける |
| 飲む | ボタン | `Pyrite9/DrinkCan/Drink` | 缶を口に運んで一口。**先に開けてください**（未開封の缶・空き缶では何も起きません） |
| 持ち替え | トグル | `Pyrite9/DrinkCan/SwapHand` | 缶を反対の手へ |

同期パラメーター: **12 ビット**（`Out`・`Opened`・`Level`・`Drink`・`SwapHand`、すべて `Pyrite9/DrinkCan/` の下）。アバター全体の上限は 256 ビットで、超えるとアップロードできません。
パラメーターは保存されません。アバターを読み込み直すと、缶はしまった状態に戻ります。ほかのパラメーター（`OpenBtn`・コンタクト・センサー）はローカルだけです。

## ゲーム内での動き

| | デスクトップ | VR |
|---|---|---|
| 取り出す | メニュー `取り出す` | 同じ |
| 開ける | メニュー `開ける` | **反対の手の人差し指**でプルタブに触れる（メニューのボタンも使えます） |
| 飲む | メニュー `飲む`。缶が口へ行って戻る（1.6 秒）、一口 | 缶の上を少しのあいだ**口に当てる**と一口。一度離してまた当てると次の一口（メニューのボタンも使えます） |
| 投げる | `取り出す` をオフ。缶が前に落ちて少し転がる | 手を振りながら `取り出す` をオフにすると、その方向へ飛ぶ。**空き缶は振るだけで投げられます**（最後の一口の 1 秒後以降） |
| 持ち替え | メニュー `持ち替え` | 同じ |
| 新しい缶 | `取り出す` をオフにしてまたオン | 同じ |

- 投げた缶は床に落ちて転がって止まり、8 秒後に消えます（新しい缶を取り出したときも消えます）。
- 缶を開けたり飲んだりできるのは本人だけです。缶・開いた状態・飲み物の量・投げた缶はほかのプレイヤーにも見えます。
- 音: 開ける音と着地音はみんなに聞こえます（2 m までは最大音量、5 m で聞こえなくなります）。飲む音は本人にだけ聞こえます。それぞれの音量はインスペクター（サウンド）で変えられます。

## 設定（Drink Can コンポーネント）

メニュー言語を日本語にしたときのインスペクターの表示名です。

| 区分 | 項目 | 意味 |
|---|---|---|
| 基本 | メニュー言語 | `EN` / `日本語` / `한국어`。メニューの表示（ビルド時に反映）とインスペクターの言語。初期値 EN |
| | 出す手 | 右手（初期値）/ 左手。取り出したときに缶を持つ手。メニューの **持ち替え** でプレイ中に変えられ、アバターを読み込み直すとこの手に戻ります |
| | 手の形 — 指で缶を握る | オン（初期値）: 缶を持っている間はその手の指が缶を握り、その手の指トラッキングは止まります。オフ: 指はそのまま |
| 缶 | サイズ | 350（66 × 122 mm、初期値）/ 500（66 × 168）/ 250 スリム（53 × 133）/ 190 コーヒー（53 × 104）/ カスタム。選ぶと高さ・直径に値が入ります |
| | 高さ・直径 | mm（高さ 60〜220、直径 45〜90）。変えるとサイズが「カスタム」になります。ゲージをダブルクリックするとプリセットの値に戻ります |
| | ラベル | 缶のまっすぐな胴に巻く画像。**空 = 無地のアルミ。** **テンプレートを開く** を押すと選んでいるサイズ用のテンプレートが、**ラベルの作り方** を押すとガイドが開きます（「ラベルを描く」） |
| | ラベルの合わせ方 | 引き伸ばし（胴いっぱい）/ 比率維持（画像の比率のまま一周。横長なら上下に金属の帯、縦長なら上下が切れる）/ 繰り返し（缶のまわりに並べる） |
| 飲み物 | 飲み物の色 | 飲み口から見える色 |
| | 飲む回数 | 空になるまでの回数（3〜10、初期値 6） |
| | 泡 | なし / 炭酸（コーラ・サイダー）/ ビールの泡（初期値） |
| | 泡の色 | 泡の層と、開けたときの泡・しぶきの色 |
| サウンド | 開ける音 | プルタブを起こして開ける音。周りの人にも聞こえます。1 = VRChat のアバターで出せる最大、0 = 鳴らさない（初期値 1） |
| | 飲む音 | 一口ごとの飲む音。自分にだけ聞こえます（初期値 0.5） |
| | 着地音 | 投げた缶が床に落ちる音。周りの人にも聞こえます（初期値 1） |
| 微調整 | 大きさの倍率 | 手に対する缶の大きさ（0.5〜2）。1 = 実物大の手に実物大の缶 |
| | 手のひらから外へ / 指先の方へ / 親指の方へ | 手を基準に缶を動かします（単位 m、アバターの基準サイズ換算）。反対の手では左右対称 |
| | 回転 | 缶を軸のまわりに回す（度） |
| | 指先へ傾ける / 手のひらから傾ける | 缶の中心を軸に傾ける（度） |
| 手の形 | 合わせ方 | **自動**（初期値）: 指が缶に触れるまで曲げ、手がいちばん自然に閉じる位置に缶を置きます（ビルドごとに数秒、頂点の多い手では最大 20 秒ほど。握れる形が見つからないときは手動の形を使います）。**手動**: 指のスライダー（ヒューマノイドの筋肉値。動かすと手動に） |
| | 初期の形に戻す | スライダーを初期の手の形に戻します |
| | 書き出し… / 読み込み… | 手の形と持ち位置・回転・傾きを `.json` に保存、または読み込み（ほかのアバターの缶にも。読み込むと手動になります） |

インスペクターにはほかに次のものがあります（表示はメニュー言語に従います）:

- **バージョン**: 1 日 1 回 GitHub に最新バージョンを問い合わせ、新しいバージョンがあれば知らせます（下の「補足」）。
- **手に持った姿をプレビュー**: いまの設定でアバターのコピーを作り、手に缶を持たせます（数秒かかります）。Scene ビューだけで、シーンには保存されません。**オンの間、元のアバターは Scene ビューで隠れます。** オフにすると元に戻ります。設定を変えたら **更新** を押してください。
- **最後のビルド**: 直前の Play・Build & Test・アップロード・プレビューの結果（アバター名・時刻・缶の倍率・手の長さ・出す手・飲む回数・警告）。ビルドログとこの README を開くボタン付き。**確認** を押すと、見た警告をそのアバターでは畳んでおけます。
- **更新履歴**: この版の変更点（この README から読み込みます）。

## ラベルを描く

- **くわしい手順: `Labels/LabelGuide_jp.md`**（インスペクターのラベル欄の **ラベルの作り方** ボタンでも開けます）。テンプレートの見かた・ラベルの合わせ方・カスタムサイズ・画像のコツ。
- `Labels/` にサイズごとのテンプレートがあります: `DrinkCan_LabelTemplate_350ml.png`、`_500ml`、`_250mlSlim`、`_190gCoffee`（カスタムサイズ用に 2:1 の `DrinkCan_LabelTemplate.png`）。
  どれも横 2048 px で、その胴とちょうど同じ縦横比です。10 mm の方眼・正面の範囲・継ぎ目・安全な余白が描いてあります。
  **テンプレートと同じ大きさで描けば**、引き伸ばしでもゆがみません。テンプレートの円が缶の上でも丸ければ正しい比率です。
- 画像の左右の端は飲み口の下の継ぎ目で合わさり、画像の真ん中が正面です。
- `Labels/DrinkCan_Label_PyriteLager.png` はプレハブに入っている見本のラベルです。2:1 なので、350 ml ではインスペクターに「引き伸ばしで少しゆがみます」と出ますが、問題ありません。
- サイズごとの見本ラベルもあと 4 枚あります（架空のブランド、サイズごとに 1 枚）。同じ **サイズ** を選び、Project ウィンドウから PNG を **ラベル** 欄にドラッグしてください:
  `DrinkCan_Label_WhiteStatic_500ml.png`（エナジードリンク、500 ml）・`DrinkCan_Label_RidgeDry_350ml.png`（ラガー、350 ml）・`DrinkCan_Label_NightLimeCola_250mlSlim.png`（ライムコーラ、250 ml スリム）・`DrinkCan_Label_DailyBean_190gCoffee.png`（コーヒー、190 g）。
- 自作のラベルは `Assets/Pyrite9/DrinkCan/` の中ではなく、自分用のフォルダ（例: `Assets/MyLabels/`）に置いてください。
- 自分の画像を入れると、次の Play やアップロードで **NDMF** のウィンドウ（Console にも）に「Some of your textures have mip streaming disabled.」が出ることがあります。そこの **Auto Fix** を押してください。または画像を選び、インポート設定の **Streaming Mipmaps** をオンにして **Apply**。VRChat SDK のビルダーにはこの項目は出ません。

## 困ったとき

Console の警告は英語で出ます（`Build failed` だけは赤いエラーとしてのみ出ます）。インスペクターの **最後のビルド** には同じ警告がメニュー言語で出ます（下の表の括弧内）。

| Console のメッセージ（`[Pyrite9 Drink Can] WARN …`）または症状 | 対処 |
|---|---|
| インポート直後に `error CS0246: The type or namespace name 'nadena' could not be found` や `error CS0234: … 'modular_avatar' does not exist in the namespace 'nadena.dev'` などの赤いエラーが出て、Play・ビルドができない | Modular Avatar（と NDMF）が入っていません。VCC / ALCOM で Modular Avatar を追加すると、Unity の再コンパイル後にエラーは消えます。 |
| 缶がピンク色になる、金属の見た目がおかしい | lilToon がないか古すぎます。lilToon 2.x を入れてください（「導入」）。 |
| `The can needs a humanoid avatar with a VRC Avatar Descriptor — not built`（ヒューマノイドアバターが必要です） | ヒューマノイドのアバター（Rig: Humanoid、ルートに VRC Avatar Descriptor）だけに対応しています。 |
| `Hand or head bone missing — not built`（手または頭のボーンがありません） | アバターのヒューマノイドのボーン割り当て（手・頭）を確認してください。 |
| `No lip-sync visemes — the mouth is guessed from the view position`（リップシンクのビセームがありません） | VRC Avatar Descriptor でリップシンクのビセームを設定するか、View Position を調整してください（このままだとデスクトップで飲むとき缶が口に届かないことがあります）。 |
| `Hand lengths differ by more than 10 % …`（左右の手の長さが 10 % 以上違います） | 缶の大きさは「出す手」に合わせます。たいてい問題ありません。反対の手で違和感があれば大きさの倍率で調整してください。 |
| `Right/Left hand: hand / index finger bones missing`、`no skinned mesh on the hand`、`no hand vertices on …`（標準の持ち位置、手の形なし） | その手は指の形なしの標準の持ち位置になります。指のボーン割り当てを確認してください。 |
| `Right/Left hand: the hand pose does not fit this avatar …`（手の形がこのアバターに合いません） | その手の指はコントローラーのままです。**手の形 ▸ 合わせ方** を **手動** にし、プレビューを見ながらスライダーで調整して **更新** を押してください。 |
| `Right/Left hand: the hand sinks … mm into the can`（手が缶にめり込みます） | **手のひらから外へ** で缶を動かすか、**大きさの倍率** を下げてください。 |
| `… DrinkCan components — only the first one is built`（DrinkCan コンポーネントが … 個あります） | 缶はアバターに 1 つだけ。余分なものを削除してください。 |
| `Build failed: …`（ビルドに失敗しました）、Console に赤いエラー | 缶が入っていないか、不完全です（アバターのほかの部分はビルドされます）。赤いエラーと `Logs/Pyrite9_DrinkCan_build.txt` を送ってください（「お問い合わせ」）。 |
| `Material template missing …`、`liquid mask material not found`、`particle shader not found`、`foam texture missing`、`sound … not found`、`throw particle mesh not made`、`no metal material` | パッケージのファイルが足りないか、プレハブが編集されています。アバターの `DrinkCan` オブジェクトを削除して `DrinkCan.prefab` を入れ直し、だめならパッケージをインポートし直してください。 |
| ドリンク缶のメニューが出ない | プレハブがアバターの外にあるか、「— not built（作られていません）」の警告でビルドが止まっています（上の表）。直したらビルド・アップロードし直してください。 |
| メニューが英語になる | インスペクターの **Menu language**（日本語表示では **メニュー言語**）を **日本語** にしてビルドし直してください。 |
| `飲む` を押しても何も起きない | 先に缶を開けてください（`開ける`、VR は反対の手の人差し指でプルタブ）。空き缶は飲めません。新しい缶を取り出してください。 |
| 振っても投げられない | 振って投げられるのは**空き缶**だけです（最後の一口から 1 秒待ってください）。どの缶も `取り出す` をオフにすれば投げられます。 |
| 指で開けても反応しない | **反対の**手の人差し指でプルタブのリングに触れてください。デスクトップは `開ける` ボタン。 |
| 缶を持つ手の指が動かない | 缶を持っている間の仕様です。指を自由にしたいときは **手の形 — 指で缶を握る** をオフにしてください。 |
| 手の中の缶の位置がおかしい | プレビューを見ながら微調整（手のひらから外へ・指先の方へ・親指の方へ・回転・傾き）、または手の形を調整してください。 |
| 缶が大きすぎる・小さすぎる | 大きさは手とアバターの背丈に合わせます。プレビューを見ながら **大きさの倍率**（0.5〜2）で調整してください。 |
| 開ける音・着地音がほかの人に聞こえない | 相手側であなたのアバターの音声が許可されていて（VRChat の Safety・アバターを表示）、アバター音量が上がっている必要があります。5 m 離れると聞こえません。開ける音・着地音が 0 になっていないかも確認してください。 |
| 飲む音が聞こえない | **飲む音**（初期値 0.5）を上げ、VRChat の音声設定でアバター音量を確認してください。 |
| SDK でパラメーターが 256 ビットを超えていると表示される | 缶は同期パラメーターを 12 ビット使います。ほかのギミックのパラメーターを減らすか、同期をやめて空けてください。 |
| ラベルがぼやける・ゆがむ・継ぎ目で切れる・黒や白のまだらが出る | `Labels/LabelGuide_jp.md`（「画像のコツ」「ラベルの合わせ方」）を見てください。テンプレートの大きさで描く、Compression を High Quality に、透明は使わない。 |
| 投げた缶が床をすり抜ける | 缶が着地するのは Default・Environment レイヤーのコライダー（ワールドの床）だけで、それ以外はすり抜けます。 |

## 更新・削除

- **更新:** 新しいパッケージを上からインポートします（すべてチェックしたまま Import）。設定はシーンの `DrinkCan` オブジェクトに保存されているので、そのまま残ります。`Assets/Pyrite9/DrinkCan/` の中のファイル（プレハブ・マテリアル・テンプレート）は変更しないでください。更新で上書きされます。自作のラベルや書き出した `.json` は自分用のフォルダに置いてください。
- **アバターから外す:** アバターの `DrinkCan` オブジェクトを削除します。Hierarchy でオブジェクトをオフにしても、缶はビルドから**外れません**。
- **プロジェクトから消す:** 先にアバターから缶を外し、それから `Assets/Pyrite9/DrinkCan/` フォルダを削除します。アバターの `DrinkCan` オブジェクトに「Missing (Mono Script)」と出たら、そのオブジェクトを削除してください（Missing Script があると SDK はアップロードしません）。

## 補足

- ヒューマノイドのアバターのみ。缶はアバターに 1 つ。
- FX レイヤー 7 つと Gesture レイヤー最大 3 つ（1 つは空。ほかは缶を持っている間、持つ手の指だけを動かします。手の形がオフならなし）を使います。レイヤーはアバターの Write Defaults の設定に自動で合わせるので（Modular Avatar の「Match Avatar Write Defaults」）、WD オン・オフどちらのアバターでも使えます。
- Action・Base・Additive レイヤーは使わないので、GoGo Loco やエモートと一緒に使えます（デスクトップで飲むときも、動くのは缶だけで腕は動きません）。Gesture レイヤーで指を動かすほかのギミックがあると、握る形が上書きされることがあります。
- 液面の水平はアバターのルート基準です。アバターを傾けるステーションでは一緒に傾きます。
- 投げた缶はローポリのコピー（プルタブ・飲み口なし）で、見る人ごとに落ちる場所が少し違うことがあります。
- 着地音は缶が手の真下に落ちたものとして鳴らしています。強く投げると、実際より少し早く、手の真下あたりで鳴ります。床が手から 6 m より下にあると着地音は鳴りません。
- デスクトップで飲むとき、少しのあいだ缶が視点のすぐ前に来ます。
- Unity エディターで Drink Can のインスペクターを開くと、1 日 1 回 GitHub（`api.github.com`）にこのパッケージの最新バージョンを問い合わせます。送る情報はありません。バージョンの文字をクリックするとすぐに確認し直します。
- パフォーマンス（350 ml・ビールの泡）: 約 24,000 ポリゴン（缶 21,864）、マテリアルスロット最大 7、PhysBone 3（傾き・振りのセンサー）、Contact レシーバー 2 + センダー 1、Constraint 7、パーティクルシステム 4（投げた缶を含む・コリジョンあり。炭酸なら 5）、オーディオソース 2、VRC Raycast 1、メニューアイコン 5（256×256）。ライトなし。缶をしまっている間もすべて数えられます。
